# Plan groupes Facebook - A SELVA / Nyllo Canella

Objectif : promouvoir A SELVA dans des groupes Facebook pertinents sans spam, en respectant les règles de chaque groupe.

## Étape 1 - Préparer la liste

Pour chaque groupe, noter le nom, le lien, le pays, la ville ou région, le thème, le nombre de membres visible, les règles, l’autorisation de publier, la validation admin et le statut.

## Étape 2 - Classer les groupes

Catégories utiles : booking, concerts Belgique, concerts France, musiciens locaux, Brésil, latino, afro, diaspora, house, techno, world music, global bass.

## Étape 3 - Adapter le texte

Ne pas publier le même texte partout.

- Booking : message professionnel court.
- Concerts : annonce artistique avec vidéo.
- Brésil / latino : racines brésiliennes, danse, percussions.
- Électro / house : machines, afro-house, organic house, global beats.
- Musiciens : collaboration, plateau, première partie ou soirée commune.

## Étape 4 - Publier manuellement

1. Lire les règles du groupe.
2. Vérifier si l’autopromotion est autorisée.
3. Adapter le texte.
4. Publier ou demander l’autorisation à un admin.
5. Noter la date dans le fichier.
6. Suivre les commentaires et messages reçus.

### Règle de tri

Pour chaque résultat Facebook, garder seulement les groupes qui remplissent au moins 2 critères :

- groupe actif récemment ;
- publications musicales autorisées ;
- public local ou professionnel ;
- concerts / bars / festivals / danse / culture ;
- pas uniquement petites annonces hors musique ;
- pas trop de spam visible.

### Ordre de publication recommandé

Ne pas poster partout le même jour.

- Jour 1 : 3 groupes Belgique.
- Jour 2 : 3 groupes Paris / Île-de-France.
- Jour 3 : 2 groupes Hauts-de-France.
- Jour 4 : 2 groupes afro/latino/Brésil.
- Jour 5 : 2 groupes house / global bass.

Attendre les réponses et commentaires avant de continuer.
