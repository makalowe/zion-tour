# Planning Facebook Belgique - A SELVA / Nyllo Canella

Objectif : publier proprement dans les groupes Facebook belges, sans spam, avec vérification des règles avant chaque publication.

Période conseillée : 2 semaines.

## Règles de base

- Ne jamais publier dans plus de 3 groupes par jour.
- Lire les règles du groupe avant publication.
- Si l’autopromotion est interdite, demander l’autorisation à un admin.
- Adapter le texte au thème du groupe.
- Noter chaque action dans le fichier de suivi.
- Relancer seulement après 7 à 10 jours, et uniquement si c’est pertinent.

## Texte demande admin

Bonjour,

Je travaille avec A SELVA, le projet Samba Tech de Nyllo Canella, multi-percussionniste brésilien basé en Belgique.

Le live mélange percussions afro-brésiliennes, machines électroniques et énergie de danse. Je voulais savoir si je peux partager une courte présentation du projet dans votre groupe, avec une vidéo et les liens officiels.

Merci d’avance,

Zion Tour

## Suivi à faire après chaque publication

À noter dans le fichier CSV :

- date de publication ;
- groupe ;
- texte utilisé ;
- statut : publié, en attente admin, refusé, à relancer ;
- commentaires utiles ;
- noms de lieux ou contacts donnés ;
- réponse privée reçue ;
- prochaine action.

## Indicateurs à suivre

- Nombre de groupes vérifiés.
- Nombre de groupes où la publication est autorisée.
- Nombre de posts publiés.
- Nombre de commentaires reçus.
- Nombre de pistes de lieux obtenues.
- Nombre de contacts programmateurs récupérés.
- Nombre de réponses positives.

## Priorité après le planning

Les groupes qui donnent des réponses doivent être transformés en vraies pistes CRM : lieu, contact, ville, type de date possible, statut et prochaine relance.
