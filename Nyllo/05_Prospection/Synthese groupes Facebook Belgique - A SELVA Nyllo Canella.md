# Groupes Facebook Belgique - A SELVA / Nyllo Canella

Objectif : préparer les groupes Facebook belges à vérifier manuellement pour promouvoir A SELVA sans spam.

Fichier de suivi : `Groupes Facebook Belgique - A SELVA Nyllo Canella.csv`

## Limite importante

Facebook ne permet pas d’extraire proprement tous les groupes sans connexion. Le fichier contient donc des recherches Facebook directes prêtes à ouvrir. Pour chaque résultat, il faut garder seulement les groupes actifs et compatibles.

- Concerts Bruxelles
- Sorties Bruxelles concerts spectacles
- Événements Bruxelles

- Concerts Liège

- Brésiliens à Bruxelles

À faire ensuite :

À faire avec prudence :

- Organic House Belgium
- House Music Belgium

Objectif : trouver collectifs, clubs et scènes organiques. Ne pas vendre comme world music, mais comme live électro-percussif.

### 6. Groupes professionnels

À vérifier :

- Booking concert Belgique
- Programmation concerts Belgique
- Festivals Belgique
- World Music Belgium
- Musiques du monde Belgique
- Centres culturels Belgique
- Fête de la musique Belgique

Objectif : trouver programmateurs et appels à artistes.

## Critères pour garder un groupe

Garder le groupe si :

- il est actif récemment ;
- il accepte les publications musique / concerts ;
- il n’est pas saturé de spam ;
- il concerne la Belgique ou une ville utile ;
- les membres peuvent être organisateurs, musiciens ou public de concerts.

Éviter le groupe si :

- les règles interdisent l’autopromotion ;
- le groupe est uniquement petites annonces hors musique ;
- les publications sont anciennes ;
- les admins refusent les liens externes ;
- le groupe est trop éloigné du projet.
